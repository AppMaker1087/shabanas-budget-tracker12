# Shabanas Budget Tracker

A simple daily budget tracker made with Lua + LÖVE.

## App
- Name: Shabanas Budget Tracker
- Version: 1.0.0
- Package ID: com.mano.shabanabudgettracker

## Build
Use the GitHub Actions workflow under `.github/workflows/build-android.yml`.
Run it manually from the Actions tab, then download the generated APK from the workflow artifacts.
